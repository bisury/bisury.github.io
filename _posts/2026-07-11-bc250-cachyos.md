가족용 게임 머신이므로 **Desktop Mode 한글 입력을 먼저 고치고, Game Mode는 최소한만 건드린다.**

> **먼저 알아둘 점**
>
> Steam의 `Korean` 화면 키보드는 키 배치이고, `fcitx5-hangul`은 한글을 조합하는 입력기다. Desktop Mode의 KDE와 Game Mode의 Gamescope/Steam은 서로 다른 세션이어서 Desktop에서 되는 설정이 Game Mode에 자동으로 이어지지 않는다.

## 1. Desktop Mode 한글 입력 고치기

Desktop Mode의 Konsole에서 설치 상태를 맞춘다.

```sh
sudo pacman -Syu fcitx5 fcitx5-hangul fcitx5-configtool fcitx5-gtk fcitx5-qt
```

설치 후 다음 순서대로 한다.

1. 앱 메뉴에서 `Fcitx 5 Configuration`을 연다. 터미널에서는 `fcitx5-configtool`이다.
2. `Only Show Current Language`를 끄고 `Hangul`을 찾아 오른쪽 목록에 추가한다.
3. 오른쪽 목록에 `Keyboard - English (US)`와 `Hangul`이 모두 있는지 확인한다.
4. KDE `System Settings → Keyboard → Virtual Keyboard`에서 `Fcitx 5`를 선택한다.
5. 로그아웃하지 말고 **완전히 재부팅**한다.
6. Desktop Mode로 다시 들어가 브라우저 주소창에서 `Ctrl + Space`를 누르고 `가나다`를 입력한다.

> **가끔 한글 표시만 되고 입력되지 않는 이유**
>
> 시스템 언어·글꼴과 입력기는 별개다. 메뉴가 한글로 보이는 것은 로케일/글꼴이 있다는 뜻일 뿐, 해당 세션에서 Fcitx 5가 실행되고 `Hangul` 엔진이 선택됐다는 뜻은 아니다.

### 그래도 Desktop에서 안 되면

아래 세 줄의 결과만 저장한다.

```sh
pacman -Q fcitx5 fcitx5-hangul fcitx5-configtool fcitx5-gtk fcitx5-qt
fcitx5-remote
fcitx5-diagnose > ~/fcitx5-diagnose.txt
```

- `fcitx5-remote`가 `0`, `1`, `2` 중 하나를 출력하면 Fcitx 5에는 연결된 것이다.
- 아무 연결도 안 되면 Virtual Keyboard가 `Fcitx 5`인지 다시 확인한다.
- KDE Wayland에서는 임의로 `fcitx5 -d`를 자동 시작하거나 `/etc/environment`에 변수를 먼저 넣지 않는다. KWin이 Fcitx 5를 시작하게 두는 것이 현재 권장 설정이다.

## 2. Game Mode의 한글 입력

Desktop Mode에서 한글 입력이 확인된 뒤에만 시험한다.

1. Game Mode의 Steam Chat 입력 칸을 연다.
2. 외부 물리 키보드에서 `Ctrl + Space` 후 한글 입력을 시험한다.
3. `Steam + X` 화면 키보드의 Korean 레이아웃도 따로 시험한다.

둘은 결과가 다를 수 있다. Gamescope 안의 Steam 입력은 Desktop KDE의 입력 경로와 다르고, Steam 화면 키보드 자체도 별도 입력 모듈을 사용한다. 따라서 화면에 한글 자판이 보이는데 영문만 입력되는 경우, Fcitx 5 재설치만 반복해도 해결되지 않을 수 있다.

> **최소 노력 원칙**
>
> Game Mode 한글 때문에 Gamescope 세션 파일이나 `/usr/share` 아래 스크립트를 직접 수정하지 않는다. 업데이트 때 덮어써지고 Steam 화면 키보드 문제까지 해결한다는 보장도 없다. 가족용 게임 머신이라면 Steam Chat은 휴대폰으로 쓰고, 긴 한글 입력은 Desktop Mode에서 하는 편이 안정적이다.

## 3. Discord 설치와 Game Mode에서 사용하기

가장 관리하기 쉬운 설치 방식은 Discover의 Flatpak이다.

1. Desktop Mode에서 `Discover`를 연다.
2. `Discord`를 설치하고 한 번 로그인한다.
3. Steam Desktop에서 `Games → Add a Non-Steam Game to My Library`를 연다.
4. Discord가 목록에 있으면 선택해서 추가한다.
5. Game Mode로 돌아가 Library의 `Non-Steam`에서 Discord를 실행한다.

목록에 없다면 Steam의 `Browse`로 다음 실행 파일을 지정한다.

```text
/usr/bin/flatpak
```

Steam 바로가기의 Launch Options는 다음으로 둔다.

```text
run com.discordapp.Discord
```

Discord를 먼저 실행해 음성 채널에 들어간 뒤 Steam 메뉴에서 게임을 실행하면 동시에 떠 있을 수 있다. 다만 Game Mode에서 Discord와 게임 사이 전환, 화면 공유, 오버레이는 일반 데스크톱만큼 매끄럽지 않을 수 있다. 음성 채팅만 필요하면 휴대폰 Discord가 가장 손이 덜 간다.

Flatpak Discord는 샌드박스 때문에 Game Activity/Rich Presence가 기본으로 제한될 수 있다. 가족 음성 채팅 목적이라면 별도 권한 수정 없이 그대로 쓰는 것을 권장한다.
